# Create Project Verifier

Inspect runtime, scripts, ports, dependencies, environment, existing automation, and public seams. Ask only what cannot be observed. Create `.cursor/skills/verify-<project>/SKILL.md` with exact Launch, Doctor, Drive, Evidence, Cleanup, and Helpers commands plus `features/README.md`. Add deterministic helpers rather than placeholders. Launch safely, verify readiness, drive one feature through the real boundary, capture action and side effect, clean up, and preserve evidence. A verifier is incomplete until this real path succeeds.
