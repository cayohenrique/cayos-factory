# Maintain Project Verifier

Compare verifier commands and feature map with current runtime/source. Reproduce the failure, update only grounded commands/helpers/features, run Doctor and one affected real path, preserve evidence, and renew capability-lock hashes. Never remove a check solely to regain READY, replace real driving with test-only endpoints, or hide cleanup failures.
