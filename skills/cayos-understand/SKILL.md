# Understand

Used by `/cayos-mode`. Auto mode writes `prepare.md` instead of this gated brief.

Consume the snapshot, `$RUN/context.md`, project guidance, and only code needed to test behavior. Resolve environmental facts from the repository. Challenge vague domain terms, ask one decision at a time with a recommendation, and give a 100–200 token ELI5 summary with one analogy. Propose the highest practical test seam and `verifiableLocally`. Do not write application code or refetch the tracker.
