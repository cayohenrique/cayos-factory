# Understand

Consume the snapshot, `$RUN/context.md`, project guidance, relevant ADRs, and only code needed to test behavior. Resolve environmental facts from the repository. Challenge vague domain terms, ask one decision at a time with a recommendation, and give a 100–200 token ELI5 summary with one analogy. Propose the highest practical test seam in the same brief and state `verifiableLocally: true|false` (false when the seam only exists after a deploy the agent may not perform). Do not write application code or refetch the tracker. Return decisions, glossary ownership, acceptance interpretation, test seam, risks, and unresolved blockers for explicit approval.
